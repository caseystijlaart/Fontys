= Approach

Throughout the project, I am following the scrum methodology. 
Sprints are utilized to track progress and plan for the next steps. 
Each sprint typically spans a month, with adjustments made for holidays.
At the end of a sprint, a sprint demo is conducted to showcase the work and accomplishments achieved during that sprint. 

== Test Approach
To ensure a seamless software implementation, I have integrated testing into the project. 
Testing takes different forms, each focusing on different aspects of the project. 
The primary testing methods employed in this project are unit testing and integration testing, which help ensure the quality and functionality of the software.
