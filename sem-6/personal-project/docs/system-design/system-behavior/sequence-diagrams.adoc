= Sequence diagrams

In this section different scenarios are considered per use case and the corresponding interactions are described by sequence diagrams.
The modules from the previous section are used as objects in these diagrams.
In some sequence diagrams the actors from the use cases appear to be an object in a diagram, since they Interact with the system by sending or receiving messages.
