= Introduction

== Purpose

This test plan outlines the testing approach for the embedded system designed to transform environmental data into musical compositions. 
It covers the verification of user, functional, and non-functional requirements outlined in the System Design Document.

== Scope

The testing will focus on validating the key functionalities of the system, including environmental data collection, musical composition generation, algorithm switching, and database interactions.

== Objectives
- Verify that the system collects environmental data accurately.
- Ensure the correct generation of musical compositions based on the collected data.
- Confirm the ability to switch algorithms for musical composition.
- Validate proper storage and retrieval of data in/from the database.
