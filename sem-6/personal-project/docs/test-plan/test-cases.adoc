= Test Cases

== Collect Environmental Data (UC01)

=== Test Case 4.1.1: Verify Data Collection

. **Description:** Confirm that the system starts collecting environmental data at startup.
. **Procedure:** Power on the system and observe data collection status.
. **Expected Result:** Environmental data collection starts without errors.
. **Type of Testing:** Unit Testing (for data collection functionality)

=== Test Case 4.1.2: Handling No Connected Sensors

. **Description:** Test the system's response when attempting to collect data without connected sensors.
. **Procedure:** Disconnect sensors, initiate data collection, and observe the system's response.
. **Expected Result:** System provides an appropriate error message.
. **Type of Testing:** Negative Testing (for error handling)


== Generate Musical Composition (UC02)

=== Test Case 4.2.1: Verify Musical Composition Audibility

. **Description: **Confirm that the system generates a musical composition that is audible over the speakers.
. **Procedure: **Request a musical composition through the interface and listen for the output over the speakers.
. **Expected Result: **A unique musical composition is generated and can be heard clearly over the speakers.
. **Type of Testing: **Component Testing (for composition generation and audible output)

=== Test Case 4.2.2: Handling No Collected Data

**Description: **Test the system's response when attempting to generate a composition without collected data.
**Procedure: **Clear collected data, request a musical composition, and observe the system's response.
**Expected Result: **System provides an appropriate error message.
**Type of Testing: **Negative Testing (for error handling)

== Change Musical Composition (UC03)

=== Test Case 4.3.1: Verify Algorithm Switching

. **Description: **Validate the system's ability to change the musical composition algorithm through the interface.
. **Procedure: **Change the algorithm through the interface and observe the resulting musical composition.
. **Expected Result: **The musical composition reflects the selected algorithm.
. **Type of Testing: **Component Testing (for algorithm.switching functionality)
