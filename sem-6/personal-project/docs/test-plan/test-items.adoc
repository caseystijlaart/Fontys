= Test Items

. Controller Unit (CU): The central processing unit for the system.
. Environmental Data Unit (EDU): Collects data from the system's environment.
. Database (DB): Stores and manages data generated by the system.
. Interface (IF): Provides an application interface for external interactions.
. Raspberry Pi 4: Responsible for making decisions and generating musical compositions.
. Arduino Nano 33 IoT: Collects environmental data.
. Environmental Sensors: Various sensors used to measure data.
. Speakers: Output device for the generated musical composition.
