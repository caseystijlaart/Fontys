= Finance

While the primary objective of this project is centered around the development of the prototype, it's essential to acknowledge the potential need for specific hardware components that may not be available at the ISSD department. 
To address this potential requirement and ensure the project's successful execution, a financial plan has been established.

== Hardware Acquirement

In the event that specific hardware is necessary for the project, the project team will assess this with the HTES during the planning phase. 
This assessment will involve identifying any hardware components or equipment that cannot be sourced internally within the ISSD. 
These could include unique sensors, microcontrollers, or other specialized devices essential for the prototype's functionality.

== Collaboration with HTES

To cover the financial costs for any of the non-available hardware, the project team will approach the HTES for funding, as they are the client.
Upon approaching the HTES, the necessary hardware is discussed to validate the purchase.
Based on the result of the discussion, the funding is allocated or a different solution has to be found.
