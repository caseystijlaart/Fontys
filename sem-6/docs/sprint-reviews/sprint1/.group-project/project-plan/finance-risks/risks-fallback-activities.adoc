= Risks and Fallback Activities

With every project risks are involved. 
Each risks with their own impact and solution.
To display the risks we could potentially could run into, how we could solve them and ultimately prevent them, see <<Risk and Fallback Activities>>.

.Risk and Fallback Activities
|===
| Risk | Prevention activities included in the plan | Fall-back Activities       

| Running out of time.| Make a concrete plan with margins. Planning a bit more time for each phase can help to get behind when problems do occur.| Discuss with coaches where to go from now.             

| Absence of a team member.| Have clear communication on the current situation. And if the absences of a team member take too long, direct action can be taken.| Contact a different team member for the needed help.                                                                                                                                                                     
| Miscommunication.| Be sure to attend the meetings and communicate the current progress and what the plans are. If something doesn't line up, this can be discussed right away. | Make use of the different communication channels, and if necessary, meetings to get back on the same page. Besides that, the GItLab version control can be used to revert any changes that were made but not wished for. 

| Hardware issues.| Plan ahead making sure that everything will be there on time and if issues do occur contact the right person right away.| Communicate the problems with the team and find a solution on how it can be solved. In the meantime, documentation can be picked up.                                

| Late change in requirements.| Keep in close touch with the project lead, to keep track of what's going on and to get an hint of changes.| Discuss what is feasible and/or of the change in requirements is truly  necessary.                     

| Software not up to their standards.| Have frequent code reviews to keep track of how your code fits into their standards.| Discuss the situation and find possible solutions on how to make it up to their standards.                           

| Unplanned additions or work that are added to the work load. | Keep in close touch with project lead, to keep track of how the project is coming along and the wiggle room of additions is.| Come to an altermatum with the project lead to make sure both parties do not suffer any consequences.
|===
