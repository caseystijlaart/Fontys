Coursework and graduation-internship repository for Casey Stijlaart's Fontys ICT program.
Each semester lives on its own branch (`semester-3` … `semester-7`); **this branch
(`semester-8`) is the active graduation internship project.**

## What this is

Semester 8 is a graduation internship at **MindLabs** (Fontys, Tilburg): researching,
designing, and building an embedded, non-camera sensing system that estimates a visitor's
real-time 3D position and height inside the Holobox interaction space, so its Virtual Human
can react appropriately (e.g. kneel down for a child).

Full context, goals, and planning: [`sem-8/docs/project-plan/project-plan.adoc`](sem-8/docs/project-plan/project-plan.adoc)
(compiled PDF alongside it).

## Repo layout

- `sem-8/docs/project-plan/` — the project plan (AsciiDoc source + generated PDF)
- `sem-8/src/firmware/` — C++ embedded firmware (CMake, GoogleTest, clang-tidy, cppcheck)
- `sem-8/src/pipeline/` — Python processing/ML pipeline (pytest, ruff, mypy)
- `.devcontainer/` — Docker dev environment with the full toolchain preinstalled
- `.github/workflows/` — CI/CD: `ci.yml` builds/tests/lints the code and updates the coverage
  badges below, `docs.yml` rebuilds PDFs from AsciiDoc automatically
- `badges/` — coverage badge images shown above, regenerated by `ci.yml` on every push

## Getting started

1. Open the repo in VS Code and choose **Reopen in Container** (needs Docker + the Dev
   Containers extension) — this installs cmake, g++, clang-tidy, cppcheck, python, pytest,
   ruff, and mypy for you, so nothing needs to be installed on your machine directly.
2. Build & test the firmware:
   ```
   cmake -S sem-8/src/firmware -B sem-8/src/firmware/build
   cmake --build sem-8/src/firmware/build
   ctest --test-dir sem-8/src/firmware/build --output-on-failure
   ```
   For a coverage report, reconfigure with `-DENABLE_COVERAGE=ON` and run `gcovr` afterwards.
3. Test the pipeline:
   ```
   cd sem-8/src/pipeline && pytest
   ```
   For a coverage report: `pytest --cov=pipeline --cov-report=term-missing`.
4. Editing the project plan or future docs: edit the `.adoc` files under `sem-8/docs/`; the
   PDF regenerates automatically on push via `docs.yml` — no local Ruby/Asciidoctor install
   needed.
