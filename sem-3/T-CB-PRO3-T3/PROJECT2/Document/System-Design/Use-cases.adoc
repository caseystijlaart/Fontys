= Use Cases
In this section the interaction between the actors and system are described with the help of the use cases.
Regarding to the actors, the ultrasonic sensor is seen as an actor as well due to roll it has in the complete system. In the tables <<table-UC001>> and <<table-UC001>> the use cases are described. The use case diagram is displayed in <<use-case-diagram>>.

== Description

[[table-UC001]]
.UC_001
|===
|UC_001             | Move in straight line.
|Description        | The robot moves in a straight line.
|Actor              | Robot
|===

[[table-UC002]]
.UC_002
|===
|UC_002             | Turn random direction.
|Description        | When an object comes within 10cm, the robot makes a random turn in degrees.
|Actor              | Ultrasonic Sensor, robot
|===

== Diagram

[[use-case-diagram]]
.Use case diagram
[plantuml,format=svg]
----
@startuml

left to right direction
actor Robot as robot
actor "Ultrasonic"  as sensor

package "Robot System" {
    usecase "Turn random direction" as turn
    usecase "Move in straight line" as straight
}
robot --> turn
robot --> straight

sensor -up-> turn

@enduml
