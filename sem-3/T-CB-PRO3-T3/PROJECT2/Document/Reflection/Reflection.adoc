= Reflection

== 360 degrees servo
When programming the servo a slight offset in the the tControl. These values did fall ito the range that has ben mentioned in the Parallax Feedback 360° High-Speed Servo  datasheet. Besides that, as mentioned, one of the servo's has been placed backwards. This results in an opposite result. To resolve this the speed had to be negative when wanting to go forward and positive when going backwards.The found tControl values in microseconds and the found tControl per speed in cm/s can be seen in the given tables. 

.tControl values in microseconds
|===
|                   |Forward max    |Forward min    |Backwards min  |Backwards max 
|Wheel 1            |1730           |1530           |1473           |1255
|Wheel 2            |1730           |1530           |1473           |1255
|===

.tControl values in speed (cm/s)
|===
|                   |Forward max    |Forward min    |Backwards min  |Backwards max 
|Wheel 1            |51.31          |0              |0              |-51.31
|Wheel 2            |-51.31         |0              |0              |51.31 
|===
